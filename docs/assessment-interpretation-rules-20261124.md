# 量表解读规则（v1）：每个量表一条评判标准

日期：2026-11-25　｜　代码：`AI_WebApi.Services/AITools/Assessment/AssessmentInterpretationRules.cs`

---

## 0. 规则从哪来

三条硬约束决定了规则能写多细：

1. **只写能追溯的**。分级要么来自产品自己出的报告文案，要么来自公开量表标准；两者都没有的量表，一律只报分数、不判读。
2. **依据随结果返回**。每条解读都带 `basis[]`（依据原文）和 `cautions[]`（使用限制），Agent 可以直接引用，不能自己发挥。
3. **缺信息就拒绝判读**。最典型的是 MoCA-B：分界值依赖受教育年限，而系统没存这个字段，所以直接返回“未判读”。

参考材料（2026-11-24 群里提供）：

| 文件 | 提供了什么 |
| --- | --- |
| `mMRC呼吸困难评分.pdf` | 0–4 级每级的文字描述，是“分级 + 描述”这种写法的样板 |
| `报告.pdf`（Barthel 100 分） | 产品自带「得分说明：日常生活独立」，证明产品已有分数→说明映射 |
| `蒙特利尔认知评估量表（MoCA-B）.pdf` | 30 分制，**按 10 个维度出分并画雷达图**，且报告自带「开始/结束/用时」 |

> mMRC 不在现有 13 个量表目录里，本轮只作为写法参考，未接入。

## 1. 已建立的规则

### AD8 认知障碍自评表（type 1）

| 区间 | 分级 | 说明 |
| --- | --- | --- |
| 2 – 8 | 达到源报告关注线 | 本次得分 X 分，达到源报告提示的关注线（≥2 分）。 |
| 0 – 1.99 | 未达到源报告关注线 | 本次得分 X 分，未达到源报告提示的关注线（≥2 分）。 |

- **依据**：满分 8 分（8 题 × 选项分 1/0/0.5）；源报告 `ScoreExplain` 原文「得分≥2 有可能为早期失智表现，建议进行专业诊断和评估。」
- **证据级别**：`source_reported`（产品自己写的文案）
- **限制**：自评筛查，不等于诊断；关注线未经临床签核。
- **额外能力**：可用选项分复算总分并与源报告比对。

### ADL 量表-Barthel 指数（type 2）

| 区间 | 分级 |
| --- | --- |
| 100 | 独立 |
| 61 – 99 | 轻度依赖 |
| 41 – 60 | 中度依赖 |
| 21 – 40 | 重度依赖 |
| 0 – 20 | 完全依赖 |

- **依据**：产品报告样例「100 分 → 得分说明：日常生活独立」；其余区间采用 Barthel 通用分级。
- **证据级别**：`standard_reference`（通用分级，未与产品逐条核对）
- **限制**：描述当下功能状态，不代表康复效果。

### GAD-7 广泛性焦虑量表（type 5）

| 区间 | 分级 |
| --- | --- |
| 15 – 21 | 重度 |
| 10 – 14 | 中度 |
| 5 – 9 | 轻度 |
| 0 – 4 | 无或最低 |

- **依据**：GAD-7 通用分级；满分 21 分。
- **证据级别**：`standard_reference`
- **限制**：询问最近两周感受；分级未签核。

### 蒙特利尔认知评估量表 MoCA-B（type 11）

**不判读。** 返回：

- `level = unverified`、`band_label = 未判读`
- 说明：「本次得分 X 分（满分 30）。MoCA-B 的判读需要结合受教育年限，系统内未登记该信息，因此只呈现分数，不做判读。」
- **依据**：MoCA-B 满分 30；分界值需按受教育年限选择；`dbuser` 没有受教育年限字段。

这是本轮**唯一一条“有文档但故意不判读”**的规则——因为规则依赖的字段在库里不存在，硬判会出错。

### 其余 9 个量表

没有可用文档，`Interpret()` 返回 `null`，报告里显示「该量表尚未建立可追溯的评判标准，仅呈现分数，不做解读」。

## 2. 返回契约

每一条记录多了一个 `interpretation` 对象：

```json
{
  "level": "descriptive",
  "band_label": "达到源报告关注线",
  "summary": "本次得分 3 分，达到源报告提示的关注线（≥2 分）。",
  "basis": [
    "AD8 共 8 题，每题选项分值 1 / 0 / 0.5，满分 8 分。",
    "源报告内置说明原文：「得分≥2 有可能为早期失智表现，建议进行专业诊断和评估。」"
  ],
  "cautions": ["AD8 是自评筛查工具，结果为提示性信息，不等同于诊断。"],
  "evidence_status": "source_reported",
  "evidence_source": "dbreport.ReportDetails.ScoreExplain"
}
```

`level` 只有两个值：

- `descriptive`：套用了分级，只描述“落在哪一档”，不做诊断；
- `unverified`：没有判读（缺规则或缺字段）。

没有规则时整个对象为 `null`，而不是空壳。

## 3. 图片报表怎么用这些规则

`02 · 评分标准与解读` 区块直接渲染规则表：

- 列出全部区间，**当前分数所在行高亮**；
- 下方列出「解读依据」和「使用限制」；
- 规则被阻断时（MoCA-B）显示阻断说明，不显示区间表。

这样即使某条记录没有逐题数据，02 区也不会空——它展示的是“这个量表怎么读”。
